# ERP Print — Tài liệu người dùng

Hướng dẫn sử dụng hệ thống ERP Print (quản trị sản xuất in ấn), phiên bản 1.1 — 30/09/2026.

Mở trực tuyến qua GitHub Pages (xem phần About → Website), hoặc tải `index.html` về mở bằng trình duyệt — file đã nhúng sẵn toàn bộ ảnh minh họa.

Nội dung: sơ đồ 8 chặng của đơn hàng, trang chủ theo vai trò sau đăng nhập, nhiệm vụ từng vai trò, hướng dẫn chi tiết từng phân hệ (Kinh doanh → Điều độ → Prepress → Xưởng → QC → Giao hàng → Tài chính → Quản lý → Admin), quy tắc nghiệp vụ & FAQ.
